# 📚 Extractor Académico

Aplicación web desarrollada con **Python y Streamlit** para facilitar la extracción y organización automatizada de información relevante contenida en artículos académicos.

🌐 **Aplicación web:**
https://extractoracademic2-svh8c78qfjhxaxtgfw3xvv.streamlit.app/

---

## 📌 Descripción

**Extractor Académico** es una herramienta orientada a investigadores, docentes y estudiantes que necesitan analizar grandes cantidades de artículos científicos de manera más rápida y organizada.

La aplicación permite procesar documentos académicos y obtener información relevante de cada publicación, reduciendo el tiempo necesario para realizar tareas de revisión y sistematización de literatura científica.

### Información que puede extraerse

* 📄 Identificador o título del artículo
* 📝 Nombre/título del artículo
* 👤 Autor(es)
* 📅 Año de publicación
* 📖 Resumen
* 🔑 Puntos clave relevantes
* 📊 Organización de la información para análisis posterior
* 📑 Exportación de los resultados a Excel

## 🎯 Objetivo

El objetivo de **Extractor Académico** es proporcionar una herramienta de apoyo para la revisión, clasificación y sistematización de literatura científica, especialmente útil en proyectos de investigación, tesis, revisiones de literatura y revisiones sistemáticas.

La herramienta **no sustituye el análisis crítico del investigador**. Los resultados obtenidos deben ser revisados y validados antes de utilizarse en publicaciones académicas.
